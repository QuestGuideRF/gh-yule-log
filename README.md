# GitHub Yule Log (gh-yule-log)

Расширение для, превращающее ваш терминал в уютный новогодний камин: анимированное ASCII‑пламя или «зеленая» версия в стиле графика вклада GitHub. Внизу бежит тикер последних коммитов вашего репозитория.

![Демонстрация](screencap.gif)

## ✨ Особенности
- Запускается как `gh`‑расширение: `gh yule-log`.
- Два режима визуализации: классический огонь или `--contribs` в палитре графика вкладов GitHub.
- Анимация на базе `tcell` с плавным «пламенем» и живыми цветами.
- Нижний тикер показывает сообщения коммитов и авторов из `git log` (до 20 последних).
- Поддержка переменной `YULE_LOG_GIT_DIR` для указания репозитория, из которого читать логи.
- Любая клавиша останавливает анимацию.

## 🚀 Быстрый старт

### Требования
- Установленный и настроенный `gh` (GitHub CLI).
- Терминал с поддержкой ANSI‑цветов.
- Go 1.21+ (только если собираете или дорабатываете локально).

### Установка
```bash
# Ставим из GitHub Marketplace
gh extension install leereilly/gh-yule-log
```

## 📁 Структура проекта
- `main.go` — основная логика анимации, отрисовка, флаги, тикер git‑логов.
- `fire_go_test.go` — тесты парсинга `git log` и обработки флага `--contribs`.
- `images/` — готовые GIF‑демки (классический и contribs‑режим).
- `screencap.gif` — превью, используемое в README.
- `scripts/` — сценарии VHS для записи демо (`generate-gif-*.tape`).
- `go.mod`, `go.sum` — модули и зависимости (основная библиотека — `tcell`).

## 🛠 Использование
```bash
# Классический огонь
gh yule-log

# Режим в стиле графика вкладов GitHub
gh yule-log --contribs
```

Советы:
- Нажмите любую клавишу, чтобы выйти.
- Установите `YULE_LOG_GIT_DIR=/path/to/repo`, если хотите читать логи не из текущего каталога.
- Тикер берёт до 20 последних коммитов и выводит: сообщение и «by Автор N ago».

## 🧪 Технологии
- Go 1.21
- GitHub CLI (расширение `gh`)
- `tcell` (терминальная графика и цвета)
- VHS (сценарии записи GIF‑демо)

Подпись относится к текущей версии проекта.
